LootZone - ملفات تحديث السيرفر (Render + GitHub)
================================================

الملف الذي يلزم استبداله في مستودع GitHub:
  backend/api/order.php

طريقة التحديث:
1) فك ضغط LootZone_Server_Update.zip.
2) افتح مستودع LootZone على GitHub.
3) افتح المسار backend/api/.
4) استبدل order.php بالملف الموجود في هذه الحزمة، مع الحفاظ على نفس المسار والاسم.
5) اعمل Commit changes. إذا كان Render مربوطاً بالمستودع مع Auto-Deploy، سيبدأ النشر تلقائياً. وإلا افتح Render واضغط Manual Deploy > Deploy latest commit.
6) في Render > الخدمة > Environment تأكد من وجود:
   TELEGRAM_BOT_TOKEN
   TELEGRAM_CHAT_ID
   لا تضع القيم الحقيقية في GitHub أو داخل التطبيق. إذا سبق نشر التوكن، ألغِه وأنشئ واحداً جديداً من BotFather.
7) لا تغيّر API URL في التطبيق ما دام عنوان الخدمة هو:
   https://lootzone-2rqc.onrender.com/backend/api/order.php

ماذا يفعل هذا التحديث؟
- يرسل Gmail مستقلاً في رسالة Telegram، ولا يستبدله بـ Player ID.
- يرسل Player ID عندما يكون موجوداً.
- يرسل وسيلة التواصل المختارة وبياناتها.
- يحسب رسوم USDT بنسبة 7% على السيرفر نفسه، ولا يعتمد على الإجمالي الذي يرسله التطبيق.
- يرسل المبلغ والرسوم والإجمالي إلى بوت Telegram.

مهم:
- هذه الحزمة لتحديث Backend على GitHub/Render فقط.
- تغييرات واجهة التطبيق (app.js والصور وCSS وJava) موجودة في مشروع Android، وتحتاج إعادة بناء APK وتوزيعه على المستخدمين؛ نشر Backend وحده لا يحدّث واجهة التطبيق المثبتة.
- يجب أن تكون استضافة PHP مجهزة بامتداد cURL وأن تسمح باتصالات HTTPS الصادرة إلى api.telegram.org.
- لا ينفذ هذا الكود تحويل USDT فعلياً؛ هو يستقبل طلباً ويرسله للإدارة للمراجعة والتواصل مع العميل.
